# opencv-basic-image-processing
Bài tập thực hành #01  Xử lý ảnh số cơ bản với thư viện OpenCV
Bài thực hành này chủ yếu để cho sinh viên:
- làm quen với các thao tác xử lý ảnh cơ bản
- Hiểu rõ bản chất toán học và cơ chế vận hành của các thuật toán xử lý ảnh
- Rèn luyện tư duy phản biện trong việc so sánh và đánh giá hiệu năng cũng như chất lượng giữa các thuật toán tự cài đặt và các hàm có sẵn trong thư viện OpenCV
YÊU CẦU:
1. Sinh viên tự cài đặt thủ công các thao tác xử lý ảnh cơ bản bằng cách sử dụng 
thư viện OpenCV. 
● Biến đổi màu - Color transformation 
● Biến đổi hình học - Geometric transformation 
● (Các) thuật toán làm trơn ảnh - Image smoothing algorithm(s) 
● (Các) thuật toán phát hiện biên cạnh - Edge detection algorithm(s) 
2. So sánh: 
● tiến hành so sánh kết quả và hiệu năng với các hàm có sẵn trong OpenCV.
